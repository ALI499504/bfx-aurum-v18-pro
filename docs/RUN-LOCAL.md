# تشغيل البوت محلياً — دليل عملي

كل ما تحتاجه على جهازك الآن: محرك، قاعدة بيانات، شموع، واجهة، جسر MT5.

---

## 1) تشغيل سريع (لا يحتاج طرفية MT5)

```bash
cd ~/bfx-aurum-bot/app
npm install                 # مرة واحدة (~570 حزمة)
npx prisma generate
npx prisma db push          # المخطط متوافق مع db/custom.db المرفق
npx next dev -p 3000        # → http://localhost:3000
```

`.env` مطلوب ويُولَّد تلقائياً:

```
DATABASE_URL=file:/home/kali/bfx-aurum-bot/app/db/custom.db
BFX_ALLOW_STALE_SNAPSHOT=1
```

- `BFX_ALLOW_STALE_SNAPSHOT=1`: يسمح للمحرك بالعمل على لقطة الشموع المحفوظة
  (`db/mt5-feed-snapshot.json` — 201,929 شمعة حقيقية) دون جسر حي. مفيد للتحليل
  والباك تيست والعرض. **لا يُستخدم للتداول الحي** — الشموع تبقى بتواريخها الحقيقية
  ولا تُزحزح.
- بدونه: أي مسار يحتاج «بيانات حديثة» (`/api/signals`, `/api/chart`, `/api/forecast`)
  يرجع 503 حتى يتصل الجسر، وهو السلوك الصحيح في الإنتاج.

## 2) بيانات حيّة حقيقية (طرفية MT5)

الجسر مرفق في `public/mt5-bridge.py` (+ `public/mt5-setup.cmd` لويندوز).

1. شغّل MetaTrader 5 وسجّل الدخول (JustMarkets-Demo في هذا الحساب).
2. شغّل الجسر على نفس جهاز المتصفح/الخادم؛ سيدفع الشموع إلى
   `POST /api/mt5/ingest` على الخادم.
3. بعد أول دفعة تختفي الحاجة إلى `BFX_ALLOW_STALE_SNAPSHOT` — كل المؤشرات تصبح لحظية.

التحقق:

```bash
curl -s localhost:3000/api/mt5/status | head -c 200
# "connected": true ... "counts": {"5m": ..., "1h": ...}
```

## 3) فحوص الحالة

```bash
npx tsc --noEmit                                   # exit 0
curl -s localhost:3000/api/system/health           # checks[] كلها ok/تنبيهات صريحة
curl -s localhost:3000/api/basket | head -c 200    # السلة على بيانات حقيقية
```

## 4) الواجهة الأحدث (المُنزَّلة من المنصة) مربوطة بخادمك المحلي

`site/` هي واجهة النسخة المنشورة (14 تبويباً). لتشغيلها على محرّكك المحلي:

```bash
cd ~/bfx-aurum-bot
PORT=4321 UPSTREAM=http://localhost:3000 node scripts/serve.mjs
# → http://localhost:4321
```

وضع التشغيل بدون أي اتصال بالمنصة:

```bash
PORT=4321 MODE=offline node scripts/serve.mjs   # يخدم لقطات api/ المحفوظة
```

## ما هو مدعوم فعلياً في الواجهة الأحدث محلياً

| التبويب | الحالة | الملاحظة |
|---|---|---|
| لوحة القيادة / الشارت / التنبؤ | ✅ | شموع حقيقية من لقطة القرص |
| الإشارات الحية | ✅ | نفس محرك `signals` |
| سجل الصفقات / حسابي | ✅ | من آخر باك تيست + حالة MT5 |
| الباك تيست والتقارير | ✅ | 297 صفقة محفوظة في `custom.db` |
| السلة المعتمدة | ✅ | محسوبة من الصفقات الحقيقية |
| المدير الآلي | ✅ | قرارات مبنية على عيّنة ≥ 30 صفقة |
| المدرب الذكي | ✅ | تقرير من الباك تيست |
| القواعد العليا / المؤشرات | ✅ | 28 قاعدة في هذه النسخة (النسخة الأحدث: 38) |
| الاستراتيجيات A–W | ⚠️ | الأسماء والتبويبات تظهر، لكن تحكم الحالات (case1/case2) وتفعيل 25 استراتيجية غير موجود في هذا المحرك (A–O + Z فقط) |
| جدولة الجلسات / سلم الأولويات | ⚠️ | معرّفات الجلسات متوافقة؛ بنية `strategyParams` الأحدث غير مولّدة عمداً بدل تلفيقها |
| الضبط الذاتي | ⚠️ | يعرض التقرير المحفوظ فقط؛ `POST /api/tuner` يرجع 501 برسالة صريحة (البحث الشبكي غير موجود في هذا المحرك) |
| J.A.R.V.I.S | ⛔ | المسارات منقولة وتعمل، لكن القسم مُغلق بقرار المالك (`src/lib/jarvis-flag.ts`) |

هذا الجدول مقصود: لم أوصل أزراراً بواجهة لا تنفّذ شيئاً. كل تحكم يظهر لك هنا
يكتب فعلاً في المحرك أو في قاعدة البيانات.
