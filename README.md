## المفقود المتبقي (بدقّة، بلا تجميل)

المصدر المنزَّل بتاريخ 2026-11-04، والنسخة المنشورة اليوم أحدث منه بأسبوع. الفارق
ليس «ملفات ناقصة» بل **ميزات طُوّرت على المنصة بعد التصدير**:

1. **25 استراتيجية (A–AA) بحالاتها** — محرك هذه النسخة يعرف A–O + Z. الواجهة الأحدث
   تعرض التبويب كاملاً، لكن تحكم الحالات لا يصل لمحرك لا يملكها. لم أوصل أزراراً وهمية.
2. **بحث شبكي / ضبط ذاتي حقيقي** — غير موجود؛ `tuner` يعرض تقريراً محفوظاً ويرفض البدء صراحة.
3. **القواعد العليا**: 28 قاعدة هنا مقابل 38 في النسخة الحيّة (أضيفت لاحقاً).
4. **جلسات/أولويات بشكل `strategyParams`** — بنية بيانات أحدث؛ تعمّدت عدم تلفيقها.
5. **J.A.R.V.I.S**: الكود منقول ويعمل، لكنه مُغلق بقرار المالك (`src/lib/jarvis-flag.ts`) — كما في النسخة الحيّة.
6. البيانات في اللقطة تنتهي **2026-11-04**. للتحديث: شغّل الجسر (بيانات حيّة) أو أعد التقاط
   `api/` ثم ادمج. لاحظ أن `/api/chart` في المنصة يخدم 800 شمعة كحد أقصى لكل طلب.

سدّ الفجوة 1–4 يحتاج قراراً هندسياً: إعادة بناء تلك الأجزاء على المحرك الحالي (عمل حقيقي
لا استرجاع)، أو طلب تصدير أحدث من المنصة إن بقيت متاحة.
