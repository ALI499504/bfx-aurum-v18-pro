# BFX AURUM v18 PRO — بوت تداول الذهب XAUUSD

ناسخ تداول حقيقي: **الموقع = عقل القرار، والجسر = منفّذ على طرفية MT5 على جهاز المالك**.

## للمحادثة الجديدة أو أي وكيل ذكاء اصطناعي

1. اقرأ أولاً وبكامل: **`AGENTS.md`** في جذر هذا المستودع — الخريطة والدستور وسير العمل وRunbook.
2. كلمات الاسترجاع المعتمدة من المالك: **AURUM-771** (هوية المشروع) — **DOSTOR-XAU** (دستور التداول) — **BRIDGE-V22** (بنية الجسر والشفاء الذاتي).
3. واصل العمل مباشرة بلا أسئلة تمهيدية، ووفق سير عمل التعديل الإلزامي في `AGENTS.md`.

## نبذة سريعة

- **النشر المعتمد**: حاسوب المالك ويندوز **فقط** — حزمة `public/laptop/` (تثبيت مرة واحدة، تشغيل دائم، تحديث بضغطة، رابط عام للأصدقاء عبر النفق). Render أُوقف بقرار المالك.
- **الجسر**: `public/mt5-bridge.py` (v22) — بث + سحب عميق + تنفيذ حي + **شفاء ذاتي بكاش شموع محلي** — وفي حزمة اللابتوب يبث للخادم المحلي `localhost:3000` مباشرة.
- **الاستمرارية**: `2-START.bat` تشغّل الخادم + الجسر + النفق مع إعادة تشغيل تلقائي، و`4-AUTOSTART.bat` للتشغيل مع كل إقلاع ويندوز، وقاعدة SQLite محلية دائمة لا تنتهي.
- **الدستور غير قابل للنقاش**: لوت ثابت 0.01، وقف ≤ $15، بلا مارتينجيل/مضاعفة/تحريك وقف، سقف التزامن 4، سقف زمني 72 ساعة، ماجيك 771000+، شموع حقيقية 100%.
- **صمام الأمان**: بث الجسر غير طازج > 2 دقيقة → الموقع يوقف إصدار الأوامر الجديدة تلقائياً حتى عودة البث.
